# Тестирование API и трафика сайта Demoblaze

**Автор:** Жильдиров Руслан Нурланович
**Дата:** Ноябрь 2026

## 📌 Описание проекта
Данный репозиторий содержит материалы по тестированию демонстрационного сайта [Demoblaze](https://demoblaze.com). 
Фокус тестирования направлен на проверку API (через Postman) и анализ/подмену сетевого трафика (через Charles Proxy).

## 🛠️ Стек инструментов
* **Postman** — отправка API-запросов, написание автотестов (JS), работа с переменными окружения.
* **Charles Proxy** — перехват HTTPS-трафика, анализ заголовков, подмена ответов сервера (Breakpoints).
* **ОС:** Windows 11 (64-bit).

## 📂 Структура репозитория
*   📁 [charles-analysis](./charles-analysis) — анализ эндпоинтов, перехват запросов, работа с Breakpoints.
*   📁 [postman-collection](./postman-collection) — коллекция API-тестов (позитивные/негативные сценарии, автотесты на JS).
* `Defects.md` — баг-репорты (в разработке).

## 🚀 Основные проверенные сценарии (API)
* Регистрация нового пользователя / дубликата / с пустым телом.
* Авторизация (получение токена), вход с неверным паролем.
* Добавление товара в корзину и просмотр её содержимого.
* Негативные проверки (неверные HTTP-методы, несуществующие URL).
