# Тестирование API и анализ трафика

В данном репозитории собраны практические навыки работы с сетевым трафиком и API-тестированием на примере веб-приложения (Demoblaze.com).

## 🛠 Стек
- **Charles Proxy** — перехват, анализ и модификация HTTP/HTTPS трафика.
- **Postman** — создание коллекций, отправка запросов, написание автотестов.

## 📂 Структура
- 📁 [charles-analysis](./charles-analysis/) — анализ эндпоинтов, перехват запросов, работа с Breakpoints.
- 📁 [postman-collection](./postman-collection/) — коллекция API-тестов (позитивные/негативные сценарии, автотесты на JS).
