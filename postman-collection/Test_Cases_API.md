# Тест-кейсы API (Postman)

**Окружение:** Windows 11 / Postman
**Результат прогона:** 10 / 10 (Pass)

### Переменные окружения (Environment)
Перед началом тестирования в Postman создано окружение `Demoblaze` со следующими переменными:
* `sourceUrl` = `https://api.demoblaze.com`
* `valid_user` = `student_777`
* `valid_pass` = `Test123!`
* `auth_token` = *(заполняется автоматически после логина)*
